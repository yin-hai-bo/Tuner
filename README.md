# 校音器

简体中文 | [English](README.en.md)

一个免费、无广告的微信吉他调音小程序。通过手机麦克风在本地分析音高，帮助用户根据偏低、偏高或已调准的反馈调整琴弦。

## 功能

- 支持六弦吉他标准调弦：从六弦到一弦为 **E2、A2、D3、G3、B3、E4**，基准音 A4 = 440 Hz。
- 默认自动识别琴弦；点击琴头上的弦钮可切换到手动模式并锁定目标弦，开启“自动”开关可恢复自动识别。
- 通过圆形标记、偏差数字、松紧提示及琴弦／弦钮高亮提供反馈，稳定调准后显示对勾并播放提示音。
- 支持简体中文和 English，默认跟随微信语言，也可在设置中选择并记住偏好。
- 提供麦克风授权、监听中断与重试提示，以及首次使用须知确认。

自动模式首次识弦立即生效；已有目标且距上次有效结果不足 1 秒时，连续两次可靠读数指向同一新目标才切换。关闭“自动”开关默认锁定六弦。

当前仅面向单根空弦调音，不包含其他乐器、其他调弦方式、和弦识别或节拍器。点击弦钮只选择目标，不播放参考音。

## 本地运行

准备微信开发者工具，以及用于测试的 Node.js 和 npm。测试直接导入 TypeScript，并使用 Node.js 内置类型擦除接口；本仓库测试已在 Node.js 24.14.0 下运行。

1. 获取仓库后，在根目录执行 `npm install` 安装开发依赖。
2. 在微信开发者工具中导入仓库根目录，使用 `project.config.json`；小程序源码目录为 `miniprogram/`。
3. 按自己的小程序账号配置 AppID，编译后使用手机微信预览。
4. 首次进入时授权麦克风，阅读并确认使用须知后，靠近手机单独拨响一根空弦。拒绝授权后，可点击页面上的“开启麦克风权限”重新设置。

离开校音页或小程序时停止监听。监听中断或单次监听达到时长上限后，按页面提示点击“继续调音”恢复。

## 开发与验证

在仓库根目录运行：

```sh
npm test
npm run test:coverage
```

测试使用 Node.js 内置测试运行器，覆盖音高检测、PCM 分帧、选弦、稳定调准、录音生命周期、授权与语言设置等。自动化测试中的合成音频和模拟微信接口不能替代真机验证。

实时链路为：微信录音帧 → PCM 解码 → MPM 音高检测 → 目标弦与偏差计算 → 稳定判定及界面反馈。当前请求 16 kHz 单声道 PCM，按有符号 16 位小端格式解码；原始偏差在 ±3 音分内持续至少 250 ms 后判定稳定调准。界面数字是偏差档位：实际绝对音分先四舍五入，再除以 2 向上取整，并保留正负方向，例如实际 +4 音分显示 +2；该数字不参与调准判定。

人工验证时，在较安静环境中逐根拨弦，检查自动识别、手动锁弦、偏差方向与成功反馈，并检查拒绝权限、切换 Tab、切后台和中断恢复。iPhone 与 Android 微信中的完整验收仍需真机完成；已有验证记录见[产品范围与开发记录](docs/product-scope.md)。

## 隐私与使用提醒

声音仅用于本地实时调音，不上传、不主动保存录音。微信录音接口可能产生平台管理的临时文件，应用不能保证立即删除这些临时产物。匹配 `wxfile://tmp_<十六进制>.pcm` 的录音路径及开发者工具中的 `http://tmp/` 路径交由平台管理；其他路径尝试删除，失败时提供重试。

自动识弦根据音高推测目标，严重失谐时可能识别为其他琴弦；手动模式只固定目标音高，无法核实实际拨响或调整的琴弦。调整前请核对弦号、琴弦与弦钮，缓慢操作，避免过度拧紧。完整使用须知可在小程序设置中查看。
