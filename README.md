# 校音器

简体中文 | [English](README.en.md)

一个免费、无广告的微信吉他调音小程序。通过手机麦克风识别琴弦音高，用直观的反馈帮助你完成调音。

## 主要功能

- 支持六弦吉他标准调弦：从六弦到一弦为 **E、A、D、G、B、E**。
- 自动识别琴弦，也可点击琴头上的弦钮手动选择目标弦。
- 显示偏高、偏低及松紧提示，调准后通过对勾和提示音反馈。
- 支持简体中文和 English，可跟随微信语言或手动选择。
- 声音在本地处理，不上传、不主动保存录音。

## 使用方式

授权麦克风并确认使用须知后，在较安静的环境中单独拨响一根空弦，按照提示缓慢调整对应弦钮。调整前请核对所选琴弦、实际拨响的琴弦与弦钮；完整使用须知可在设置页查看。
