# 校音器：产品讨论记录

状态：第一期产品需求已由用户于 2026-10-18 确认定稿。开发按 [项目开发约定](../AGENTS.md) 分步实施，每步完成后等待用户 Review。

## 已确认

- 产品形态：微信小程序，名称为“校音器”。
- 核心用途：使用手机麦克风识别乐器音高，提示偏低、偏高或已调准。
- 第一期只支持六弦吉他的标准调弦。
- 默认自动识别琴弦，同时允许手动选弦。
- 免费、无广告，不包含节拍器等额外功能。
- 以 GuitarTuna 的调音功能为参考，做简化的调音体验。
- 面向没有调音经验的新手，显示当前第几弦、音名，以及“偏低，请缓慢拧紧／偏高，请缓慢放松”等指导。
- 不使用顺时针或逆时针作为通用提示，避免琴头结构和绕弦方式造成误导。
- 界面展示吉他琴头图片，并高亮当前琴弦对应的弦钮，配合文字指导用户调整。
- 第一期只使用左右各三个弦钮的“3＋3”琴头图，不提供其他琴头布局切换。
- 点击琴头图中的弦钮进入手动模式，锁定对应的目标弦；识别到其他音高时也不自动切换目标弦。
- 只有用户点击“自动”才恢复自动识别；界面明确显示当前模式。
- 用户点击“开始调音”后申请麦克风权限，授权成功即开始监听；监听期间可手动暂停。
- 离开小程序时停止监听；返回后不自动恢复，由用户点击继续。
- 监听因来电等原因意外中断后，立即清除音高判断，圆形回到灰色待机状态，提示“监听已中断，点击继续”；保留当前自动／手动模式及手动所选琴弦，由用户点击“继续调音”恢复，不自动重试。
- 单次监听达到平台 10 分钟时长上限后停止，清除音高判断并回到灰色待机状态，提示“本次监听已结束，点击继续”；保留当前模式和手动所选琴弦，由用户点击继续，不自动重新启动监听。
- 声音仅在手机本地用于实时判断音高，不上传、不主动保存或保留录音，不提供录音回放或历史记录。
- 接受微信录音接口产生本地临时文件；小程序在监听结束后清理临时文件。清理能力及异常退出后的处理需真机验证。
- 申请麦克风权限前简短说明：“声音仅用于本地实时调音，不上传、不保留录音。”
- 用户拒绝麦克风权限后，保留调音界面，显示“需要麦克风权限才能调音”，提供由用户主动点击的“去设置”入口，不反复弹窗。
- 未获得麦克风权限时，仍可点击弦钮查看弦号和音名，但不显示音高判断；开启权限后，由用户点击“开始调音”才开始监听。
- 音高偏差使用可左右移动的圆形标记表示，替代此前讨论的指针：偏低时圆形为红色、位于中心左侧；偏高时圆形为红色、位于中心右侧；调准时圆形居中，以绿色背景和对勾动画表示成功。
- 采用用户提供的 GuitarTuna 截图作为视觉参考：深色背景，上方为音高偏差网格及中心参考线，下方为 3＋3 琴头图。
- 网格下方统一显示一行小字：偏低时为“偏低，请缓慢拧紧”，偏高时为“偏高，请缓慢放松”，调准时为“已调准”；成功文字与绿底对勾动画、提示音共同反馈。
- 圆形标记离中心的距离随音高偏差大小变化：偏差越大越远，接近目标时向中心靠拢；移动保持平滑，超出显示范围时停在网格边缘。
- 本弦调准时播放提示音。
- 同一根弦首次稳定调准时，播放一次提示音及成功动画，随后保留静态对勾；持续调准、轻微波动和短暂无声不重复触发。
- 明确偏离后重新调准，或切换目标弦、暂停后重新开始并再次调准时，可重新触发提示音及成功动画。
- 播放调准提示音期间，保留成功画面并暂停更新音高判断，播放结束后自动恢复判断，避免将提示音当作琴弦声音；这与来电等意外中断后需手动继续的规则分别处理。
- 反馈过程中琴头图始终高亮当前目标弦对应的弦钮。
- 第一期不显示赫兹、音分等专业数值。
- 音高连续约半秒稳定在目标附近后才判定调准并显示成功动画；允许小幅自然波动，避免提示频繁跳动。具体容差留待真机验证后确定。
- 声音消失后，最后一次有效结果保留约 1 秒；随后圆形标记回到中间的灰色待机状态，提示“请拨动一根琴弦”，清除成功图形和松紧提示。
- 等待拨弦时，手动模式保留所选弦钮高亮；自动模式取消高亮，等待重新识别。
- 有声音但无法可靠识别音高时，停止给出松紧提示，圆形标记显示灰色，提示“请靠近手机，单独拨响一根琴弦”；手动模式保留目标弦，自动模式不高亮任何弦钮。
- 无法可靠识别时不直接断言“环境太吵”，避免误判原因。
- 自动模式连续约 0.3 秒可靠识别为同一根弦后，才选中或切换到该弦；确认前不根据候选弦给出松紧提示。
- 自动模式可以在上一根弦尚未调准时识别并切换到下一根弦。
- 第一期不加入已调准琴弦的进度标记，不保留各弦调准记录；琴头图只高亮当前目标弦。

## 待真机验证的参数

- “已调准”的具体音高容差（留待真机验证）。

## 已确认的第一版验收范围

- 在较安静环境中，用真实六弦吉他逐根拨响空弦，六根弦均能正确识别。
- 故意调低或调高时，圆形移动和松紧提示方向正确；调准后出现绿底对勾、成功文字及提示音。
- 自动识别与手动锁弦符合上述规则。
- 无声、识别不可靠、拒绝授权及监听中断时，反馈符合上述规则。
- 在 iPhone 和 Android 手机的微信中均完成真机验证。
- 嘈杂环境、扫弦或和弦识别不作为第一版验收要求。
- 具体音高容差需在技术核实和真机验证后确定。

## 技术核实记录（不代表已经真机验证）

- 微信官方最新 API 类型定义列出 PCM 录音格式及 PCM 分帧回调支持，可作为本地实时音高分析的候选输入；仓库现有类型定义较旧，仅注明 mp3 分帧支持，后续需处理版本差异。
- 官方类型定义注明单次录音最长 10 分钟；达到上限后停止并由用户点击继续，产品行为已确认，平台表现仍需真机验证。
- 录音与提示音播放在 iPhone、Android 微信中的兼容性，以及提示音被麦克风拾取后的影响，均待真机验证。
- 官方录音停止回调包含本地临时录音文件路径，不能直接承诺平台完全不产生录音文件；临时文件的清理能力和异常退出后的处理仍需验证。
- 来源：[微信官方 API 类型定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)。
